# Global Travel Site

Projeto estático com 3 páginas em HTML para publicação no GitHub Pages.

## Arquivos
- `index.html`
- `nossos-cursos.html`
- `trabalhar-morar-fora.html`
- `globaltravel_logo_full.png`
- `favicon.png`

## Observações
- O vídeo da home é carregado de uma URL externa.
- Criei arquivos de logo e favicon temporários para o site não ficar com links quebrados.
- Se você tiver a identidade visual oficial, é só substituir `globaltravel_logo_full.png` e `favicon.png`.
